Edit the grammar

Separate symbols with spaces. Use ε for an empty alternative. The first left-hand side is the start symbol. Capitalized names are nonterminals.

Read the notation

LL(1) means reading input from left to right, constructing a leftmost derivation, and using one lookahead token.

FIRST(α) contains the terminals that can begin strings derived from α. It also contains ε if α is nullable.

FOLLOW(A) contains the terminals that can occur immediately after A. $ marks the end of input. FOLLOW never contains ε.

α ⇒* ε means α derives the empty string in zero or more steps. This makes α nullable.

Apply the rules to every pair of distinct alternatives of the same nonterminal.

Grammar rewrites

LL(1), ambiguity, and left recursion

LL(1) requires a unique production choice with one lookahead token. An unambiguous grammar gives each valid string exactly one parse tree.

Every LL(1) grammar is unambiguous and has no left recursion. Neither property, even together with left factoring, guarantees LL(1).

What LL(1) guarantees

With LL(1), the stack top and lookahead determine each production. This gives one leftmost derivation and one parse tree.

Left recursion can return to the same leftmost nonterminal before consuming a token. For a productive grammar, the recursive alternative competes with a terminating alternative.

Left factoring moves a shared prefix before a choice. It can remove a FIRST/FIRST conflict. A FIRST/FOLLOW conflict can still remain.

CounterexampleS → A a
A → a | ε

The language is {a, a a}, with one tree per string. Yet M[A, a] has two entries.

Two groupings, two parse trees

E → E + E | id   ·   input: id + id + id

Both trees have the same leaves in the same order. Their production choices group the expression differently. Leftmost versus rightmost expansion order can describe the same tree; expansion order alone does not establish ambiguity.

Scope and conventions

The three verbal rules and their disjointness form follow the supplied Dragon Book excerpts. FIRST includes ε here; some sources use a separate nullable flag instead. SELECT is also called PREDICT.

The editable lab requires each nonterminal to be reachable from the start symbol and able to derive a finite terminal string. Otherwise, it gives a diagnostic before an LL(1) verdict. This reduced-grammar scope avoids misleading claims about useless rules.

LL(1) is decidable by these sets and table checks. General CFG ambiguity is undecidable. The lab shows authored ambiguity witnesses and proofs for specific examples; it does not claim to detect ambiguity in an arbitrary grammar.

The predictive parsing table is M[nonterminal, lookahead]. LR parsers use separate ACTION and GOTO tables.
